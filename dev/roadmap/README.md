# Roadmap

**Stage 1 of the feature lifecycle** (see `CLAUDE.md`): high-level goals for Crawl's software. This covers what we want and why, before we know how.
One file per goal, for example `fully-digital-rules.md` or `threejs-visualizations.md`.

Keep roadmap docs short, with no implementation detail. Each specific feature that serves a goal gets its own doc in
[`../planning/`](../planning/), and is listed under "Features" here.
Archive the roadmap doc once all of its features are shipped or removed.

File names: lowercase-with-dashes, e.g. `backend-rebuild.md`.

## Template
```markdown
# Goal name
**Status:** idea | active | done | dropped  ·  **Owner:** brody, maddox

## Goal
What we want, and why it matters for players and for us.
```
