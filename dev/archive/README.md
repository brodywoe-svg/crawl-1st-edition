# Archive

**Stage 5 of the feature lifecycle** (see `CLAUDE.md`). Once a feature's prototyping phase ends, with the outcome
logged in [`../DECISIONS.md`](../DECISIONS.md), move its [planning](../planning/) and [testing](../testing/) docs here with `git mv`.
That applies whether the outcome was ship, iterate or remove.
Archive a [roadmap](../roadmap/) doc once all of its features are resolved.

Before moving a doc, set its status line to the outcome and add one sentence on how it ended.

The archive is history and may be out of date. The present is described by the top-level `dev/*.md` files, so when a
feature ships, update `ARCHITECTURE.md` and `DATA-MODEL.md` too.
